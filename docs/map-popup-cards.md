# Map popup cards

All area maps, compact project maps and the regional map use `popup-card.ts` with the same `popup-model.ts` presentation. City-supplied content is inserted as text, never HTML.

The first line describes the proposed change; it is not the case ID or status. Existing public evidence can provide the short headline or, when unambiguous, homes and acreage from the same application document. The current authored project filing is a fallback only for its known source report; an unrelated/newer report cannot inherit its old figures. Otherwise the project name is the headline. The explanation is at most 25 words. Missing data is omitted. Context images remain labeled as context; concept dates remain visible. Image buttons open the existing viewer.

The existing PDF extraction schema now includes `popupHeadline` (fewer than eight words) and `popupExplanation` (one sentence, at most 25 words). These fields require the same exact source quote, page and confidence checks as other fields and may only publish from application/staff-report sources. The prompt explicitly excludes earlier neighborhood notices, existing homes and theoretical capacity. Extraction happens during collection, not map requests. This does not change the extraction version or force expensive re-extraction of all unchanged PDFs. Previously extracted usable prose/facts work immediately; new/changed reports supply the dedicated short prose fields. Failed/missing copy falls back to the name. The AI disclosure and source link live on the project page.

Map API enrichment reads a batch of case-scoped document metadata and published fields through the existing five-minute tagged timeline cache, plus the cached official area feed. It never loads PDF pages or calls the model on page views. Official feed outcomes may be displayed directly; extracted decision fields remain admin-approval gated. Pending results are labeled pending without a completed-step checkmark. Only the upcoming/current step is highlighted. A final decision ends the tracker without a future decision or stale hearing. Body names and dates use the jurisdiction registry and timezone.

The footer holds project/jurisdiction, View project and Watch. It omits case codes and duplicate jurisdiction headings. The card remains within the map; when an outline occupies the available space the map reframes to reserve room rather than squeezing all content into a tiny gap.
